# IPL Ticket Booking React Application

## About the Project
This project is an IPL Ticket Booking website developed using React JS and Vite.

## Features
- Navigation bar with Home, Matches, Book Tickets and My Bookings.
- Hero section displaying a welcome message.
- Upcoming IPL match cards.
- Reusable React components.
- Props to pass match details.
- State management using useState.
- Dynamic rendering of matches using map().

## Technologies Used
- HTML
- CSS
- JavaScript
- React JS
- Vite

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL in your browser.
